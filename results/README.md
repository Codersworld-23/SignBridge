# SignBridge Benchmark Results Directory
This folder stores the experimental benchmark evaluation, trained checkpoints, comparative performance tables, and publication-ready plots for the academic report.

Subdirectories:
- `checkpoints/`: Best model weights for all 4 evaluated architectures.
- `tables/`: Markdown, CSV, and LaTeX tables for SLR & SLT metrics.
- `plots/`: Comparison bar charts, learning curves, and confusion matrices.
- `metrics/`: Raw JSON evaluations on the held-out test split.
